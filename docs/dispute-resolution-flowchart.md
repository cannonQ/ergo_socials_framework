## Standard Dispute Resolution Process

```
Issue Occurs
    │
    ▼
┌─────────────────────────────────┐
│   Is this minor or accidental?  │
└─────────────────────────────────┘
    │
    ├─ YES → Moderator Reminder / Informal Warning → END
    │
    └─ NO
         │
         ▼
┌─────────────────────────────────────────────────────────┐
│              Moderator Action Taken                     │
│  (content removal / warning / mute / role restriction)  │
└─────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│   Does the user accept the action?  │
└─────────────────────────────────────┘
         │
         ├─ YES → END
         │
         └─ NO
              │
              ▼
┌─────────────────────────────────────┐
│     Formal Dispute Submitted        │
│      (team@sigmanauts.com)          │
└─────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│      Admin Review Initiated         │
│    • Involved admins recuse         │
│    • Full admin team reviews        │
└─────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│       Clarification Needed?         │
└─────────────────────────────────────┘
              │
              ├─ YES → Private discussion with parties
              │           │
              │           ▼
              └─ NO ──────┤
                          │
                          ▼
┌─────────────────────────────────────┐
│      Written Decision Issued        │
│    (within 10 business days)        │
└─────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│        Decision Enforced            │
│    (binding on all parties)         │
└─────────────────────────────────────┘
              │
              ▼
            END
```

---

## Emergency Override

At any point, admins may:

- temporarily restrict any participant (including admins/founders)
- remove permissions to prevent active harm
- review actions after stabilization

---

## Important Notes

- Public escalation while a dispute is under review may result in further moderation.
- Decisions are final unless new evidence emerges.
- This process exists to protect the community, not adjudicate personal vendettas.
